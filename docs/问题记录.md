### [小] SHA256SUMS.txt 漏了新加的文件（Grok，2026-11-18）
原因：[4b8f702](https://github.com/cjhkcjgk3-sys/sillytavern-red-pen/commit/4b8f702) 新增 `AGENTS.md` 和 `docs/问题记录.md` 时没有重新生成 `SHA256SUMS.txt`，清单 35 条、实际受控文件 37 个（不含清单本身）；已有 35 条校验都正确。
解决：2026-11-18 按原格式（`sha256  路径`，按 `git ls-files` 顺序）重新生成，覆盖除清单本身外的全部受控文件。
状态：已修未实机验证

### [大] 手机长按选字后没有「标记」入口
出错模型：不追究　发现者：用户　状态：已修未实机验证
- 现象：用户反馈手机上插件显示已开启，长按正文选字后“没有任何反应，也没有‘标记’入口”。
- 原因：三条会让入口静默消失的路径：选区锚点在元素节点时 `parentElement` 跳出正文被判“不在正文内”；部分安卓 WebView 长按不派发 `selectionchange`；缺少 CSS Custom Highlight 时整体暂停标记。
- 证据：[ca6ce3d](https://github.com/cjhkcjgk3-sys/sillytavern-red-pen/commit/ca6ce3d)（0.1.3），[docs/ACCEPTANCE.md](https://github.com/cjhkcjgk3-sys/sillytavern-red-pen/blob/main/docs/ACCEPTANCE.md)「0.1.3」一节。
- 解决方法：改判定方式；增加 touchend／mouseup／contextmenu／keyup 触发和短时轮询；缺高亮时改用叠加层绘制；面板加兜底入口和选区诊断。0.1.5 起点中已有标记不再要求选区折叠。
- 预防措施：触屏相关改动要在安卓实机验证；ACCEPTANCE 记录写明真实安卓长按尚未验证。
- 归类：通用部分已交待审（[加强-触屏要实机验证](https://github.com/cjhkcjgk3-sys/ai-dev-lessons/blob/main/待审/2026-11-18-Grok-加强-触屏要实机验证.md)、[失败要看得见](https://github.com/cjhkcjgk3-sys/ai-dev-lessons/blob/main/待审/2026-11-18-Grok-失败要看得见.md)）

### [小] 右下角两个按钮都看不见（不追究，0.1.1）
原因：缺少 CSS 高亮能力时 0.1.1 在 preflight 直接退出，页面没有操作条，也没有错误说明。
解决：[a3bb98f](https://github.com/cjhkcjgk3-sys/sillytavern-red-pen/commit/a3bb98f)（0.1.2）把入口移到魔术棒菜单，核心按需加载，失败仍保留入口和错误说明。
状态：已修未实机验证（真实 1.18 隔离实例已验证，用户手机未验证）

### [小] 标记要走 4 步（不追究，0.1.5 前）
原因：选中 → 魔术棒 → 红笔标记 → 标记当前选中的文字，用户反馈太繁琐。
解决：[4765fef](https://github.com/cjhkcjgk3-sys/sillytavern-red-pen/commit/4765fef)（0.1.5）新增「选中即标记」，[1e0da8c](https://github.com/cjhkcjgk3-sys/sillytavern-red-pen/commit/1e0da8c)（0.1.6）延迟改为可调。
状态：已修未实机验证

### [小] 重复标记同一范围仍提示“已标记保存”（不追究，0.1.6 前）
原因：`add()` 的返回结果没有正确解包。
解决：[1e0da8c](https://github.com/cjhkcjgk3-sys/sillytavern-red-pen/commit/1e0da8c)（0.1.6）修复，并把重叠标记合并为一条。
状态：已修未实机验证
