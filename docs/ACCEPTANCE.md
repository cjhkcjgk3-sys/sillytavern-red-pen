## 已知限制与需联测事项

1. 主机版本未提供，当前只针对指定 1.19.0 源码合同编写；不会声称所有版本通用。
2. 数据保存在当前浏览器账号的 IndexedDB，没有跨设备云同步。浏览器网站数据清理、无痕模式及系统回收需要备份恢复。
3. 原生主页面 DOM `.mes[mesid] .mes_text` 属于明确依赖。主题只改色彩通常可沿用；替换 DOM、隐藏正文、改写 `send_date` 或重组回答数组的扩展需要专项联测。无法确认时保留摘录并停止对应高亮。
4. 只支持同源原生聊天补全流程，独立或并发后台请求、文本补全、非标准端点以及 fetch 替换冲突未支持。不开额外 API 密钥设置。
5. 标记附加在宿主历史构建完成之后。不会自动挤掉历史；已估算容量不足需减少历史窗口、标记或调整配置再试。分词和多模态容量仍存在估算边界。
6. 返回来源要求该消息已加载到 DOM；如果酒馆尚未加载旧历史，会提示先向上加载历史。不会用相同文字的其他位置代替来源。
7. 不同消息分别标记；表格仅单元格内；图片、视频、iframe、复杂嵌入页面和非正文控件不支持。被选范围边界处空白不能准确映射时拒绝，不猜测。
8. 源码仓库为 `https://github.com/cjhkcjgk3-sys/sillytavern-red-pen`，支持扩展管理器使用仓库 URL 安装。源码公开不代表已经通过正式首版验收；没有执行用户生产环境安装或付费模型调用。
9. 备份完整性检查会拒绝损坏和缺字段文件；尚未设计更高版本备份迁移协议。本版不含多色、标签、逐条发送开关与跨聊天共享库。
